# Cybernetic Apparel - Tienda Virtual

Tienda virtual de ropa con estilo cyberpunk neón, desarrollada con HTML5, CSS3 y JavaScript puro (vanilla JS).

## Archivos
- `index.html`: estructura de la página y modales.
- `styles.css`: diseño cyberpunk neón (glassmorphism, cyan/magenta).
- `data.js`: catálogo de 20 prendas de tiendas colombianas y respaldo local.
- `app.js`: lógica de registro, búsqueda, carrito y consumo de API.

## Funcionalidades principales
- Registro e inicio de sesión con localStorage.
- Búsqueda básica y avanzada (categoría, precio, tienda/marca).
- Catálogo de 20 prendas con imágenes reales y precios en COP.
- Modal de detalle con características y selector de cantidad.
- Carrito de compras con total dinámico y comprobante de compra.
